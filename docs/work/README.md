# work/ —— 活的工程产物

- **这里放什么**：随产品演进的**活产物**与证据。每个小 V 的交付物（`features/<slug>/`）、需求↔测试活矩阵（`traceability.md`）。新固件需求随小 V 落在 `features/<slug>/01-requirements.md`。
- **不要放什么**：按日期沉淀的历史记录（→ `archive/`）、常青规范文档（→ `concept/`·`process/`·`standard/`·`quality/`）、**旧固件逆向参考需求**（→ `../reference/legacy-requirements/`，那是参考输入不是活产物）。
- **权威文件**：`traceability.md`（需求验证到哪的活矩阵）；每特性看 `features/<slug>/`。
